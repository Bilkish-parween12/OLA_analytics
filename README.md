# 🚖 OLA Ride Booking Dashboard | Power BI

An interactive **Power BI Dashboard** built using the OLA ride booking dataset. This dashboard provides detailed insights into bookings, revenue, cancellations, vehicle performance, and customer & driver ratings.

---

##  Project Overview

The main objective of this project is to analyze OLA ride booking data and provide meaningful business insights through interactive visualizations.

The dashboard helps identify:

- Total bookings and booking value
- Successful and cancelled rides
- Revenue trends
- Vehicle-wise performance
- Customer and driver ratings
- Cancellation reasons
- Payment method analysis
- Top customers

---

###  4. Cancellation Dashboard
